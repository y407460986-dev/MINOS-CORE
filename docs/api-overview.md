# MINOS-CORE API Overview

> **Base URL:** `http://localhost:8100/api` (default)
> **Authentication:** Bearer Token (`Authorization: Bearer <token>`)
>
> **Note:** All `/api/*` routes require a Bearer token passed via the `Authorization` header.
> The token is auto-generated by the desktop sidecar and passed to the Tauri frontend at launch.
> SSE streaming uses a short-lived query-param token instead of the header (see SSE section).
>
> **Error format (all endpoints):**
> ```json
> {
>   "detail": "Human-readable error message",
>   "code": "ERROR_CODE",
>   "failure_message": "Machine-readable failure context"
> }
> ```

## SSE (Server-Sent Events)

> SSE uses a **query-param stream token** instead of the Bearer header, because
> the browser `EventSource` API cannot set custom headers.
> Obtain a token via `POST /api/auth/stream-token` (valid for 60 seconds).

| Method | Path | Description | Auth |
|--------|------|-------------|------|
| GET | `/api/runs/{run_id}/chain/{stage}/stream?stream_token=<token>` | Stream generation progress events for a chain stage (`pfd`, `pfmea`, or `cp`). Returns `done` event immediately if no active generation. | Stream token (query) |

### SSE Events

Each event is a JSON-encoded `ServerSentEvent`:

```json
{"type": "progress", "stage": "pfmea", "run_id": 1, "current_step": "...", "total_rows": 50}
{"type": "done",     "stage": "pfmea", "run_id": 1, "total_rows": 50, "status": "completed"}
{"type": "error",    "stage": "pfmea", "run_id": 1, "message": "..."}
```
