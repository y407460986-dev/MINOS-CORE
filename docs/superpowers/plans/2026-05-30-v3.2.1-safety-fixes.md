### Task 2: Pass API token via env var instead of CLI argument

**Files:**
- Modify: `apps/desktop-tauri/src-tauri/src/lib.rs:143-150`

**Root cause:** Sidecar is spawned with `--token <value>` on the command line, which is visible to other local processes via `wmic` or `/proc/<pid>/cmdline`.

**Fix:** Remove `--token` from command args and set `MINOS_DESKTOP_API_TOKEN` environment variable before spawn. Python `auth.py` already reads this env var.

- [ ] **Step 1: Replace --token arg with env var**

In `apps/desktop-tauri/src-tauri/src/lib.rs`, lines 136-151:

```rust
// Before:
    let command = command.args([
        "--host",
        "127.0.0.1",
        "--port",
        &port_arg,
        "--token",
        &token,
        "--db-path",
        &db_path_arg,
        "--output-dir",
        &output_dir_arg,
    ]);

// After:
    let command = command
        .env("MINOS_DESKTOP_API_TOKEN", &token)
        .args([
            "--host",
            "127.0.0.1",
            "--port",
            &port_arg,
            "--db-path",
            &db_path_arg,
            "--output-dir",
            &output_dir_arg,
        ]);
```

### Task 4: Redact API token from sidecar log output

**Files:**
- Modify: `apps/desktop-tauri/src-tauri/src/lib.rs:230-233`

**Root cause:** Sidecar stdout/stderr is written verbatim to `api.log`. If the Python process ever prints the token or an Authorization header, it's persisted in plaintext.

**Fix:** Strip the known token value from log lines before writing.

- [ ] **Step 1: Add token redaction to write_log_line**

In `apps/desktop-tauri/src-tauri/src/lib.rs`, replace the `write_log_line` function:

```rust
// Before:
fn write_log_line(file: &mut File, stream: &str, line: &[u8]) {
    let text = String::from_utf8_lossy(line);
    let _ = writeln!(file, "[{stream}] {text}");
}

// After:
fn write_log_line(file: &mut File, stream: &str, line: &[u8]) {
    let text = String::from_utf8_lossy(line);
    let redacted = match SIDECAR_TOKEN.get() {
        Some(token) => text.replace(token.as_str(), "***REDACTED***"),
        None => text.to_string(),
    };
    let _ = writeln!(file, "[{stream}] {redacted}");
}
```
