## 附录：贸易商年度复评要求

| 复评项目 | 说明 |
|----------|------|
| 复评周期 | 每年一次，准入满 12 个月前 30 天启动 |
| 复评依据 | 年度供货业绩、质量表现、交期达成率、配合度 |
| 绩效考核指标 | 交货准时率 ≥ 95%、来料合格率 ≥ 99%、投诉响应 ≤ 24h |
| 降级/淘汰规则 | 连续两次 C 级降为淘汰；发生重大质量事故直接淘汰 |
| 资质更新 | 复评时需更新所有即将到期的资质文件 |
